# Nemux Ledger 0.5.1: как тестировать

Сборка для двух тестеров из одной гильдии. Аддон на английском, инструкция на русском.

## Установка
1. Если стоит 0.1.0, **удали старую папку** `RequiemLedger`. Настройки и смерти при этом сохранятся.
2. Распакуй `RequiemLedger-0.5.1.zip` и положи папку `RequiemLedger` в `Interface\AddOns\` папки Forever.
   Чтобы найти папку: Battle.net → WoW: Forever → ⚙ → **Show in Explorer**.
3. На экране выбора персонажа: **AddOns** → Requiem Ledger включён. Если он «out of date», включи **Load out of date AddOns**.
4. В игре: `/console scriptErrors 1`, чтобы видеть ошибки.

## Команды
| Команда | Что делает |
|---|---|
| `/rq` или кнопка с гербом у миникарты | открыть или закрыть окно |
| `/rq guild` | вкладка Guild |
| `/rq recipes bracer` | поиск рецепта у гильдии (Guild → Recipes) |
| `/rq feats` | вкладка Feats (ачивки) |
| `/rq report` | **отчёт для меня**: текст уже выделен, жми Ctrl+C и вставляй в Discord |
| `/rq hud` | вернуть HUD (то же делает правый клик по кнопке у миникарты) |
| `/rq hud reset` | вернуть HUD на место по умолчанию |
| `/rq buffs` | список бафов с ID |
| `/rq learn food` | «баф, который я только что получил, — это еда» (также `flask`, `elixir`) |
| `/rq death` | показать случайную фразу о смерти (не считается) |

## Чек-лист для одного
Отмечай ✅ или ❌. Если что-то не так, сделай скриншот.

**1. Загрузка и вид**
- [ ] Нет красных ошибок Lua.
- [ ] У миникарты есть кнопка с гербом. Клик открывает окно, кнопку можно перетащить по кругу, после `/reload` она на том же месте.
- [ ] Вкладка **Settings** выглядит ровно: галочки стоят под Solo / Party / Raid, ничего не наезжает.

**2. Напоминания**
- [ ] В Settings у каждого бафа есть колонка **Warn**: за сколько минут предупредить. У Sleeping Bag по умолчанию 10 минут.
- [ ] Кнопка **Test reminder**: в центре экрана появляется надпись, в чате строка, слышен звук.
- [ ] Поставь еде Warn = 25 минут и съешь еду (баф длится 30): примерно через 5 минут появится напоминание **Food runs out in 25 min**. Оно приходит один раз.
- [ ] Sleeping Bag: когда у **Well-Rested** осталось меньше 10 минут, приходит напоминание, а в HUD появляется строка.

**3. Еда и Sleeping Bag** (в 0.1.0 работали, проверь, что не сломалось)
- [ ] Без еды HUD пишет **No food buff**, после еды строка исчезает.
- [ ] Sleeping Bag вне города: **Sleeping Bag is ready**. После использования на вкладке **Me** видно: **Active · N min**.

**4. Смерти**
- [ ] Умри: в чате смешная фраза и номер смерти.

## Чек-лист для двоих (оба в одной гильдии, оба с аддоном 0.4.0)
- [ ] Вкладка **Guild** показывает гильдию, кто онлайн, уровень, зону и ранг. Эта часть работает и без аддона у других.
- [ ] Через ~10 секунд после входа второго игрока в колонке **Requiem Ledger** у него появляется `v0.4.0 · N deaths`. В шапке: «2 with Requiem Ledger».
- [ ] Один умирает: у второго в чате появляется фраза с его именем, например *«Friend kissed the floor. (death #3)»*.
- [ ] Галочка **Show guild deaths in my chat** на вкладке Deaths отключает эти сообщения.
- [ ] На вкладке Guild кнопка **Show professions**: что там? Скриншот. Это проверка, отдаёт ли Forever список профессий гильдии.

## Рецепты (нужны двое с 0.4.0)
- [ ] Каждый **один раз открывает окно своей профессии** (как для крафта). В чате: *Saved N Enchanting recipes...*
- [ ] Guild → **Recipes** → напиши 2–3 буквы рецепта друга. В строке рецепта его имя. Наведи мышь: список всех, кто умеет.
- [ ] Друг выучил новый рецепт и снова открыл окно профессии: через минуту рецепт находится и у тебя.
- [ ] Друг вышел из игры: его рецепты всё равно ищутся (имя серое).

## Ачивки (вкладка Feats)
- [ ] При первом входе: *You already have N feats* — старые достижения засчитаны тихо, без спама.
- [ ] Новая ачивка (например, смерть или уровень): надпись в центре экрана и строка в чате. У друга в чате: *Nemu earned ...*
- [ ] В колонке **GUILD** видно, у кого ещё есть эта ачивка (наведи мышь).
- [ ] Рейдовые ачивки (убить босса, не умереть, со всеми бафами) проверим в рейде.

## Таблицы (вкладка Boards, `/rq boards`)
- [ ] Слева три кнопки: **Deaths** (всего), **This week** (с еженедельного ресета), **Honor kills**. Ты и согильдийцы с 0.4.0 в списке, у первого — звание.
- [ ] Число HK совпадает с тем, что показывает игра (окно PvP / Honor).
- [ ] Кто-то с аддоном умер: справа в **Recent guild deaths** строка с именем, номером смерти и зоной.
- [ ] После своей смерти ты тоже есть в ленте, с зоной или боссом.

## 0.4.0: трекер, цены, ding, weekly, ачивки
- [ ] Guild → Recipes: **клик по рецепту** включает отслеживание (» перед названием). Справа появляется панель: реагенты «в сумках / нужно», цвет меняется, когда покупаешь.
- [ ] В панели: левый клик по рецепту = +1 крафт, правый = −1. Shift-клик по реагенту вставляет ссылку в чат.
- [ ] Цены (если стоит Auctionator или NaowhForever): в подсказке рецепта «~1g 20s» у реагентов и **Approx. cost**; в трекере внизу «Missing ~…».
- [ ] Кто-то в гильдии апнул уровень: строка в чате *X reached level N* (это работает для всех, даже без аддона). На вкладке Boards галочки: выключить или «только каждые 10 уровней».
- [ ] Boards → **Weekly report**: текст выделен, Ctrl+C в Discord. После еженедельного ресета в чате будет «Last week's guild report is ready».
- [ ] Feats: новые ачивки (HK, профессии, 100 рецептов, смерть в данже…) и кнопка **Guild goals** с прогрессом гильдии.

## Что прислать
1. Отметки по чек-листу и скриншоты.
2. Текст из `/rq report` (Ctrl+C → Discord). **Искать файл больше не нужно.**

Про файл: SavedVariables записываются только при `/reload` или выходе из игры, поэтому сразу после теста файла может не быть. Если всё же нужен: `<папка Forever>\WTF\Account\<номер или имя аккаунта>\SavedVariables\RequiemLedger.lua`.

## Известные ограничения 0.4.0
- Колонка «Requiem Ledger» и смерти гильдии видны только у тех, у кого стоит аддон.
- Во время боя с боссом игра запрещает аддонам отправлять сообщения. Сообщение о смерти уйдёт после боя.
- Список профессий гильдии берётся у самой игры. В Forever он может быть выключен; тогда в следующей версии сделаем свой через аддон.
- Проверка бафов у группы (кто без еды или фласки) появится позже.
